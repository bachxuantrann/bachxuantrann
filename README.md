## 📌 Public projects

### 🔗 url-shorten

A full-stack URL shortener built end to end, from backend to deployment.

- **Redirect path:** Redis cache-aside with negative caching, 302 redirects, circuit breakers (Resilience4j) so a Redis or Kafka outage never breaks a redirect
- **Short codes:** unique by construction (DB sequence + keyed permutation → Base62), plus custom aliases and password-protected links
- **Click analytics:** async tracking through Kafka with idempotent batch consumers, daily stats, monthly-partitioned tables, privacy-friendly (no raw IPs stored)
- **Security & abuse protection:** stateless JWT with refresh tokens, Redis rate limiting, SSRF-safe target policy, domain blocklist, abuse reports, appeals, admin moderation
- **Frontend:** React 19 + Vite + TypeScript, light/dark theme, English/Vietnamese
- **Ops:** Docker Compose, Caddy (HTTPS + rate limits), Flyway migrations, Testcontainers integration tests, CI/release workflows, OpenTelemetry → OpenObserve
